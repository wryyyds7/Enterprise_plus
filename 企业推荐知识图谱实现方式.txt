# 企业推荐知识图谱实现方式

## 一、技术栈

### Python端技术栈
- **Web框架**: Flask 2.0+ - 用于构建RESTful API服务
- **知识图谱构建**: Neo4j - 用于构建和操作图数据结构
- **数据处理**: pandas 1.5+ - 用于数据清洗和处理
- **相似度计算**: scikit-learn 1.1+ - 用于实现余弦相似度等算法
- **HTTP请求**: requests 2.28+ - 用于调用Java后端API获取数据
- **缓存**: Redis 4.0+ - 用于缓存频繁访问的图数据

### Java端整合技术
- **Feign客户端**: Spring Cloud OpenFeign - 用于调用Python服务的RESTful API
- **数据传输**: JSON - 统一的数据交换格式

## 二、输入输出

### 输入
1. **用户标签数据**
   - 格式: `{"userId": "123", "tags": ["软件工程师", "Java", "Spring Boot"]}`
   - 来源: Java后端的用户标签系统

2. **企业标签数据**
   - 格式: 通过调用Java后端的`TagClient`获取
   - API: `/entity/tag/byEntity/enterprise/{enterpriseId}`

3. **职位标签数据**
   - 格式: 通过调用Java后端的`TagClient`获取
   - API: `/entity/tag/byEntity/position/{positionId}`

### 输出
1. **企业推荐结果**
   - 格式: 
     ```json
     {
       "code": 200,
       "msg": "success",
       "data": [
         {
           "enterpriseId": 123,
           "enterpriseName": "示例科技公司",
           "relevanceScore": 0.92,
           "matchedTags": ["软件公司", "科技公司"],
           "positions": [
             {
               "positionId": 456,
               "positionName": "Java开发工程师",
               "salary": "15k-25k",
               "city": "北京"
             }
           ]
         }
       ]
     }
     ```

## 三、具体实现方式

### 1. 知识图谱构建

**节点类型**:
- 用户(User) - 属性: userId, name
- 企业(Enterprise) - 属性: enterpriseId, enterpriseName, city
- 职位(Position) - 属性: positionId, name, salary
- 标签(Tag) - 属性: tagId, name

**边类型**:
- 用户-标签(User_Tag) - 关系: "拥有标签"
- 企业-标签(Enterprise_Tag) - 关系: "属于"
- 职位-标签(Position_Tag) - 关系: "需要技能"
- 企业-职位(Enterprise_Position) - 关系: "招聘"

**构建流程**:
1. 从Java后端获取所有企业、职位和标签数据
2. 创建节点: 为每个实体创建对应的节点
3. 创建边: 根据实体间的关联关系创建边
4. 为边添加权重: 基于标签的重要性和关联性设置权重

### 2. 推荐算法

**基于标签相似度的推荐**:
1. 计算用户标签与企业标签的余弦相似度
2. 计算用户标签与职位标签的余弦相似度
3. 结合企业和职位的相似度，得到综合推荐分数

**基于图遍历的推荐**:
1. 从用户节点出发，通过标签节点遍历到相关的企业和职位节点
2. 使用PageRank算法计算节点的重要性
3. 根据路径长度和节点重要性计算推荐分数

**混合推荐策略**:
- 结合基于标签相似度和基于图遍历的结果
- 对不同用户群体采用不同的推荐权重

### 3. Java与Python整合

**Python服务端**:
- 提供RESTful API接口: `/api/recommend/enterprise`
- 接收用户标签数据，返回企业推荐结果

**Java客户端**:
- 创建Feign客户端: `PythonRecommendationClient`
- 调用Python服务的API获取推荐结果
- 代码示例:
  ```java
  @FeignClient(value = "python-recommendation", url = "http://localhost:5000")
  public interface PythonRecommendationClient {
      @PostMapping("/api/recommend/enterprise")
      AjaxResult recommendEnterprises(@RequestBody UserTagRequest request);
  }
  ```

## 五、关键模块说明

### 1. graph_builder.py
- 负责构建企业、职位、用户和标签之间的知识图谱
- 实现图的创建、节点和边的添加
- 提供图的序列化和反序列化功能

### 2. recommendation.py
- 实现基于标签相似度的推荐算法
- 实现基于图遍历的推荐算法
- 提供混合推荐的接口

### 3. data_loader.py
- 从Java后端获取企业、职位和标签数据
- 实现数据的清洗和转换
- 支持增量更新图数据

- 部署多个Python服务实例

- 实现服务健康检查和自动恢复

## 七、性能优化

1. **图数据缓存**
   - 使用Redis缓存构建好的图数据
   - 设置合理的缓存过期时间
   - 支持增量更新缓存

2. **推荐结果缓存**
   - 缓存用户的推荐结果
   - 当用户标签或企业信息变化时更新缓存

3. **算法优化**
   - 使用矩阵分解等高效算法计算相似度
   - 实现批量推荐，减少重复计算

4. **并发处理**
   - 使用多线程处理多个推荐请求
   - 优化数据库查询性能
