# 学习路径功能开发计划

## 一、数据库设计

### 1. 学习路径相关表

#### 1.1 技能表 (skill)

```sql
CREATE TABLE `skill` (
  `skill_id` bigint NOT NULL AUTO_INCREMENT COMMENT '技能ID',
  `name` varchar(255) NOT NULL COMMENT '技能名称',
  `description` text COMMENT '技能描述',
  `difficulty` int DEFAULT 1 COMMENT '难度等级(1-5)',
  `category` varchar(255) COMMENT '技能分类',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted` tinyint DEFAULT 0 COMMENT '是否删除',
  PRIMARY KEY (`skill_id`),
  INDEX `idx_name` (`name`),
  INDEX `idx_category` (`category`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='技能表';
```

#### 1.2 学习资源表 (learning\_resource)

```sql
CREATE TABLE `learning_resource` (
  `resource_id` bigint NOT NULL AUTO_INCREMENT COMMENT '资源ID',
  `title` varchar(255) NOT NULL COMMENT '资源标题',
  `description` text COMMENT '资源描述',
  `type` varchar(50) COMMENT '资源类型(视频/文档/练习/项目)',
  `url` varchar(512) NOT NULL COMMENT '资源链接',
  `thumbnail_url` varchar(512) COMMENT '资源缩略图',
  `difficulty` int DEFAULT 1 COMMENT '难度等级(1-5)',
  `duration` int COMMENT '时长(分钟)',
  `relevance` double DEFAULT 0.5 COMMENT '相关性(0-1)',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted` tinyint DEFAULT 0 COMMENT '是否删除',
  PRIMARY KEY (`resource_id`),
  INDEX `idx_title` (`title`),
  INDEX `idx_type` (`type`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习资源表';
```

#### 1.3 技能依赖关系表 (skill\_dependency)

```sql
CREATE TABLE `skill_dependency` (
  `dependency_id` bigint NOT NULL AUTO_INCREMENT COMMENT '依赖关系ID',
  `skill_id` bigint NOT NULL COMMENT '技能ID',
  `prerequisite_skill_id` bigint NOT NULL COMMENT '前置技能ID',
  `importance` double DEFAULT 1.0 COMMENT '依赖重要性(0-1)',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`dependency_id`),
  UNIQUE KEY `uk_skill_prerequisite` (`skill_id`, `prerequisite_skill_id`),
  FOREIGN KEY (`skill_id`) REFERENCES `skill` (`skill_id`) ON DELETE CASCADE,
  FOREIGN KEY (`prerequisite_skill_id`) REFERENCES `skill` (`skill_id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='技能依赖关系表';
```

#### 1.4 技能-资源关联表 (skill\_resource\_relation)

```sql
CREATE TABLE `skill_resource_relation` (
  `relation_id` bigint NOT NULL AUTO_INCREMENT COMMENT '关联ID',
  `skill_id` bigint NOT NULL COMMENT '技能ID',
  `resource_id` bigint NOT NULL COMMENT '资源ID',
  `relevance` double DEFAULT 0.5 COMMENT '相关性(0-1)',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`relation_id`),
  UNIQUE KEY `uk_skill_resource` (`skill_id`, `resource_id`),
  FOREIGN KEY (`skill_id`) REFERENCES `skill` (`skill_id`) ON DELETE CASCADE,
  FOREIGN KEY (`resource_id`) REFERENCES `learning_resource` (`resource_id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='技能-资源关联表';
```

#### 1.5 学习路径表 (learning\_path)

```sql
CREATE TABLE `learning_path` (
  `path_id` bigint NOT NULL AUTO_INCREMENT COMMENT '路径ID',
  `user_id` bigint NOT NULL COMMENT '用户ID',
  `title` varchar(255) NOT NULL COMMENT '路径标题',
  `description` text COMMENT '路径描述',
  `status` varchar(50) DEFAULT 'draft' COMMENT '状态(draft/in_progress/completed)',
  `progress` int DEFAULT 0 COMMENT '进度(0-100)',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`path_id`),
  INDEX `idx_user_id` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习路径表';
```

#### 1.6 学习路径技能表 (learning\_path\_skill)

```sql
CREATE TABLE `learning_path_skill` (
  `path_skill_id` bigint NOT NULL AUTO_INCREMENT COMMENT '路径技能ID',
  `path_id` bigint NOT NULL COMMENT '路径ID',
  `skill_id` bigint NOT NULL COMMENT '技能ID',
  `order_index` int NOT NULL COMMENT '学习顺序',
  `status` varchar(50) DEFAULT 'pending' COMMENT '状态(pending/in_progress/completed)',
  `mastery_level` int DEFAULT 0 COMMENT '掌握程度(0-100)',
  PRIMARY KEY (`path_skill_id`),
  UNIQUE KEY `uk_path_skill` (`path_id`, `skill_id`),
  FOREIGN KEY (`path_id`) REFERENCES `learning_path` (`path_id`) ON DELETE CASCADE,
  FOREIGN KEY (`skill_id`) REFERENCES `skill` (`skill_id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习路径技能表';
```

  `user_id` bigint NOT NULL COMMENT '用户ID',
  `avatar_url` varchar(512) NOT NULL COMMENT '头像URL',

  UNIQUE KEY `uk_user_active` (`user_id`, `is_active`) WHERE (`is_active` = 1),
  INDEX `idx_user_id` (`user_id`)

## 三、服务层设计

### 1. 技能服务

* SkillService：提供技能的增删改查、批量操作等功能

* SkillDependencyService：管理技能依赖关系

* SkillResourceRelationService：管理技能与资源的关联关系

### 2. 学习资源服务

* LearningResourceService：提供学习资源的增删改查、批量操作等功能

### 3. 学习路径服务

* LearningPathService：管理学习路径的创建、更新、删除等功能

* LearningPathSkillService：管理学习路径中的技能

### 4. 用户头像服务

* UserAvatarService：管理用户头像的上传、更新、删除等功能

## 四、控制器设计

### 1. 技能控制器 (SkillController)

* GET /api/skill/list：获取技能列表

* GET /api/skill/{skillId}：获取技能详情

* POST /api/skill：创建技能

* PUT /api/skill/{skillId}：更新技能

* DELETE /api/skill/{skillId}：删除技能

### 2. 学习资源控制器 (LearningResourceController)

* GET /api/resource/list：获取学习资源列表

* GET /api/resource/{resourceId}：获取学习资源详情

* POST /api/resource：创建学习资源

* PUT /api/resource/{resourceId}：更新学习资源

* DELETE /api/resource/{resourceId}：删除学习资源

### 3. 学习路径控制器 (LearningPathController)

* POST /api/learning-path：创建学习路径

* GET /api/learning-path/{pathId}：获取学习路径详情

* PUT /api/learning-path/{pathId}：更新学习路径

* DELETE /api/learning-path/{pathId}：删除学习路径

* GET /api/learning-path/user/{userId}：获取用户的学习路径列表

* POST /api/learning-path/recommend：推荐学习路径

### 4. 用户头像控制器 (UserAvatarController)

* GET /api/user/avatar/{userId}：获取用户头像

* POST /api/user/avatar：上传用户头像

* PUT /api/user/avatar/{avatarId}：更新用户头像

* DELETE /api/user/avatar/{avatarId}：删除用户头像

* PUT /api/user/avatar/{avatarId}/active：设置当前活跃头像
