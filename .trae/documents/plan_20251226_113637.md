# 服务启动测试计划

## 准备工作
1. **检查依赖服务状态**：
   - 检查Redis是否已启动
   - 检查Nacos是否已启动

2. **启动顺序**：
   - 先启动基础设施服务（Redis、Nacos）
   - 再启动核心微服务

## 执行步骤
1. **检查Redis状态**：
   ```bash
   redis-cli ping
   ```
   - 如果返回PONG，则Redis已启动
   - 如果未启动，启动Redis服务

2. **检查Nacos状态**：
   - 访问 http://localhost:8848/nacos
   - 检查是否能正常访问
   - 如果未启动，启动Nacos服务

3. **启动微服务**：
   - 使用Maven启动所有服务：
     ```bash
     mvn spring-boot:run
     ```
   - 或逐个启动核心服务：
     ```bash
     cd 模块名
     mvn spring-boot:run
     ```

4. **验证服务状态**：
   - 检查Nacos控制台，确认所有服务已注册
   - 检查服务日志，确认没有连接池错误
   - 测试核心API，确认服务正常响应

## 预期结果
- 所有服务成功启动
- 没有出现"Too many connections"错误
- 服务正常注册到Nacos
- API可以正常访问
