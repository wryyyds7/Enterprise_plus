# 管理员功能

## 0. 系统功能

### 程序员模式
- **路径**: /admin/programmerMode
- **方法**: GET
- **模块**: admin
- **描述**: 点击进入程序员模式，跳转到nacos界面（一般是8080端口）
- **状态**: 已实现
- **数据说明**: 不涉及后端数据管理，仅提供前端跳转功能

### 登录流量统计
- **路径**: /admin/statistics/loginFlow
- **方法**: GET
- **模块**: admin
- **描述**: 登录流量统计
- **状态**: 已实现
- **数据说明**: 统计用户登录的IP地址、登录时间、登录设备、登录状态等信息，支持按时间范围、IP地址等维度筛选

## 1. 用户管理

### 用户信息管理
- **路径**: /users/admin/searchUserByPage
- **方法**: GET
- **模块**: users
- **描述**: 用户搜索服务(分页)
- **状态**: 已实现
- **数据说明**: 管理用户ID、用户名、真实姓名、邮箱、电话号码、角色类型、用户状态等用户基本信息，支持分页、排序和多条件筛选

- **路径**: /users/admin/deleteUser
- **方法**: POST
- **模块**: users
- **描述**: 用户删除服务
- **状态**: 已实现
- **数据说明**: 根据用户ID删除指定用户的所有信息，包括用户基本信息、用户标签、收藏记录、活动报名记录等关联数据

- **路径**: /users/admin/updateUserStatus
- **方法**: PUT
- **模块**: users
- **描述**: 用户状态更新服务
- **状态**: 已实现
- **数据说明**: 管理用户的激活/禁用状态，支持批量更新，同时记录状态变更的操作人和操作时间

- **路径**: /users/admin/add
- **方法**: POST
- **模块**: users
- **描述**: 用户添加服务
- **状态**: 已实现
- **数据说明**: 管理新增用户的基本信息，包括用户名、密码、真实姓名、邮箱、电话号码、角色类型等，支持设置初始密码和默认角色

### 用户标签管理
- **路径**: /users/user/tags/{userId}
- **方法**: GET
- **模块**: users
- **描述**: 获取用户标签
- **状态**: 已实现
- **数据说明**: 管理用户与标签的关联关系，获取指定用户的所有标签信息，包括标签ID、标签名称、标签类型等

- **模块**: users
