# Python模块使用说明

## 一、模块概述

本项目包含两个核心Python模块，用于实现智能推荐功能：

1. **企业推荐模块** (`enterprise-recommendation/`)
   - 基于知识图谱和标签相似度的企业推荐系统
   - 使用Neo4j构建企业、职位、用户和标签的关系网络
   - 提供RESTful API接口供Java端调用

2. **学习路径推荐模块** (`learning-path-recommendation/`)
   - 基于知识图谱的个性化学习路径推荐系统
   - 构建技能依赖关系图，实现最优学习路径规划
   - 提供RESTful API接口供Java端调用

## 二、部署与运行

### 2.1 环境要求
- Python 3.8+
- Neo4j 4.0+
- Redis 4.0+
- 所需依赖见各模块的`requirements.txt`

### 2.2 安装依赖
```bash
# 企业推荐模块
cd enterprise-recommendation
py -m pip install -r requirements.txt

# 学习路径推荐模块
cd ../learning-path-recommendation
py -m pip install -r requirements.txt
```

### 2.3 配置文件

各模块的配置文件为`config.py`，包含以下关键配置：
- Flask服务端口和调试模式
- Neo4j数据库连接信息
- Redis缓存配置
- Java后端API地址
- 推荐算法参数

### 2.4 启动服务

```bash
# 企业推荐模块
cd enterprise-recommendation
py app.py

# 学习路径推荐模块
cd ../learning-path-recommendation
py app.py
```

## 三、API接口说明

### 3.1 企业推荐模块API

#### 推荐企业接口
- **URL**: `/api/recommend/enterprise`
- **方法**: POST
- **请求参数**:
  ```json
  {
    "userId": "123",
    "tags": ["软件工程师", "Java", "Spring Boot"]
  }
  ```
- **响应结果**:
  ```json
  {
    "code": 200,
    "msg": "success",
    "data": [
      {
        "enterpriseId": 123,
        "enterpriseName": "示例科技公司",
        "relevanceScore": 0.92,
        "matchedTags": ["软件公司", "科技公司"],
        "positions": [
          {
            "positionId": 456,
            "positionName": "Java开发工程师",
            "salary": "15k-25k",
            "city": "北京"
          }
        ]
      }
    ]
  }
  ```

  ```json
  }
  ```

## 四、与现有Java功能整合

### 4.1 企业推荐模块整合

#### 整合点
1. **企业推荐列表功能** (`/home/enterpriseRecommendation/list`)
   - Java端实现该API接口，调用Python企业推荐模块的`/api/recommend/enterprise`接口
   - 结合用户标签和求职偏好，返回个性化企业推荐列表

2. **企业收藏功能**
   - 利用推荐模块的相似度计算，为用户收藏的企业推荐相似企业
   - 整合路径：`/users/user/enterpriseFavorites`接口返回收藏企业时，附带推荐的相似企业

3. **标签管理功能**
   - 使用Python模块的标签相似度计算，为企业或职位推荐相关标签
   - 整合路径：`/tag/list`接口返回标签时，附带相关标签推荐

### 4.2 学习路径推荐模块整合

#### 整合点
1. **学习路径推荐功能**
   - Java端实现学习路径相关API，调用Python学习路径推荐模块的接口
   - 结合用户当前技能和学习目标，生成个性化学习路径

2. **用户技能管理**
   - 利用技能掌握度预测功能，为用户推荐适合学习的下一个技能
   - 整合路径：用户技能列表接口返回当前技能时，附带推荐的下一个技能

3. **学习资源管理**
   - 使用资源推荐功能，为用户推荐适合的学习资源
   - 整合路径：技能详情接口返回技能信息时，附带推荐的学习资源

## 五、可新增功能

### 5.1 企业推荐模块可新增功能

1. **AI企业官网识别**（已实现）
   - 集成AI企业官网判断功能，为推荐的企业添加官方网站链接
   - 实现方式：调用AI模型接口，输入企业名称，获取官方网站URL

2. **企业匹配度分析报告**
   - 为用户生成详细的企业匹配度分析报告
   - 内容包括：标签匹配情况、职位匹配度、企业文化匹配度等

3. **动态推荐调整**
   - 根据用户的浏览历史和交互行为，动态调整推荐结果
   - 使用Redis缓存用户行为数据，实时更新推荐模型

4. **多维度筛选**
   - 支持按城市、行业、薪资、规模等多维度筛选推荐结果
   - 实现方式：在API请求参数中添加筛选条件，在推荐算法中考虑这些条件

### 5.2 学习路径推荐模块可新增功能

1. **学习进度跟踪**
   - 跟踪用户的学习进度，动态调整学习路径
   - 实现方式：记录用户完成的技能和资源，定期更新学习路径

2. **学习小组推荐**
   - 为用户推荐学习同一技能或路径的学习小组
   - 实现方式：基于用户的学习路径和进度，匹配相似的学习者

3. **学习效果评估**
   - 评估用户的学习效果，提供改进建议
   - 实现方式：定期收集用户的学习数据，使用机器学习模型评估学习效果

4. **自适应学习内容**
   - 根据用户的学习风格和进度，自适应调整推荐的学习内容
   - 实现方式：结合用户的学习风格标签和学习数据，动态调整资源推荐

## 六、注意事项

1. **数据同步**
   - 确保Java后端和Python模块之间的数据同步
   - 定期从Java后端获取最新的企业、职位、用户和标签数据

2. **性能优化**
   - 使用Redis缓存频繁访问的数据和推荐结果
   - 优化Neo4j查询，使用索引提高查询效率
   - 考虑使用异步处理高并发请求

3. **错误处理**
   - 实现完善的错误处理机制，确保API接口的稳定性
   - 记录详细的日志，便于问题排查

4. **安全性**
   - 实现API接口的认证和授权机制
   - 对敏感数据进行加密处理
   - 防止SQL注入和其他安全攻击
