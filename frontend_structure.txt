前端文件结构规划

# 项目概述
本项目为企业服务平台前端，基于后端提供的API接口设计，包含AI对话、企业管理、用户管理、聊天功能等模块。

# 前端技术栈
- 框架：Vue 3
- 构建工具：Vite
- 状态管理：Pinia
- HTTP请求：Axios
- UI组件库：Element Plus
- 路由：Vue Router

# 页面跳转路径配置

## 跳转规则设计
页面跳转路径配置采用角色-模块-页面三级结构，支持根据用户角色、登录状态和业务场景动态配置跳转路径，确保系统的可扩展性。

### 1. 基础跳转规则
- **未登录状态**：所有需要认证的页面 → `/login`
- **登录失效状态**：所有需要认证的页面 → `/login?redirect={当前路径}`
- **权限不足状态**：所有权限不足的页面 → `/403`
- **页面不存在**：所有404页面 → `/404`

### 2. 角色默认跳转
- **普通用户**：登录成功 → `/home`
- **管理员**：登录成功 → `/admin/dashboard`
- **企业用户**：登录成功 → `/home/enterprise/{enterpriseId}`

### 3. 模块内跳转路径

#### 登录模块 (login)
- 登录成功 → 根据用户角色跳转（配置于 `authStore` 中）
- 注册成功 → `/login`
- 忘记密码 → `/login/forgot`

#### AI模块 (ai)
- AI对话页面 → `/ai`
- 对话历史 → `/ai/history`
- AI设置 → `/ai/settings`

#### 聊天模块 (chat)
- 会话列表 → `/chat/sessions`
- 会话详情 → `/chat/session/{sessionId}`
- 消息详情 → `/chat/message/{messageId}`
- 新建会话 → `/chat/session/new`

#### 企业模块 (enterprise)
- 企业列表 → `/enterprise/list`
- 企业详情 → `/enterprise/detail/{enterpriseId}`
- 企业编辑 → `/enterprise/edit/{enterpriseId}`
- 企业新建 → `/enterprise/new`
- 职位列表 → `/enterprise/{enterpriseId}/positions`
- 职位详情 → `/enterprise/{enterpriseId}/position/{positionId}`

#### 用户模块 (user)
- 个人中心 → `/user/profile`
- 用户设置 → `/user/settings`
- 用户列表（管理员） → `/user/list`
- 用户详情（管理员） → `/user/detail/{userId}`

#### 搜索模块 (search)
- 搜索结果 → `/search/result`

#### 主页模块 (home)
- 主页 → `/home`
- 企业推荐列表 → `/home/recommendation`
- 校园招聘活动列表 → `/home/events`
- 企业详情 → `/home/enterprise/{enterpriseId}`
- 活动详情 → `/home/event/{eventId}`
- 我的收藏 → `/home/favorites`
- 我的活动报名 → `/home/my-events`

#### 管理员模块 (admin)
- 管理员仪表盘 → `/admin/dashboard`
- 企业管理 → `/admin/enterprises`
- 用户管理 → `/admin/users`
- 活动管理 → `/admin/events`
- 内容管理 → `/admin/content`
- 数据统计 → `/admin/statistics`

### 4. 路由配置实现
```javascript
// src/router/modules/auth.js
import { getRedirectPathByRole } from '@/utils/redirect'

export default [
  {
    path: '/login',
    name: 'Login',
    component: () => import('@/views/login/Login.vue'),
    meta: {
      title: '登录',
      requiresAuth: false,
      redirectAfterLogin: true // 标记为登录后需要跳转
    }
  }
]

// src/utils/redirect.js
export const getRedirectPathByRole = (roles) => {
  // 根据用户角色获取默认跳转路径
  if (!roles || roles.length === 0) {
    return '/home' // 默认跳转
  }
  
  if (roles.includes('admin')) {
    return '/admin/dashboard'
  }
  
  if (roles.includes('enterprise')) {
    return '/home/enterprise/{enterpriseId}'
  }
  
  return '/home' // 默认跳转
}

export const getRedirectPathByConfig = (key) => {
  // 根据配置键获取跳转路径
  const redirectConfig = {
    'login.success': '/home', // 登录成功默认跳转主页，实际会根据角色动态调整
    'register.success': '/login',
    'logout.success': '/login'
    // 可扩展更多配置
  }
  
  return redirectConfig[key] || '/'  
}
```

### 6. 扩展性考虑
- **动态配置**：支持从后端接口获取跳转配置，实现动态调整
- **角色扩展**：新增角色时只需在 `getRedirectPathByRole` 函数中添加对应规则
- **模块扩展**：新增模块时只需在跳转路径配置中添加模块相关的跳转规则
- **权限控制**：结合路由守卫实现基于角色的精细化跳转控制
- **多终端适配**：支持根据不同终端类型（PC、移动端）配置不同的跳转路径

## 注意事项
1. 所有跳转路径必须在路由配置中定义
2. 跳转规则应遵循最小权限原则，避免越权访问
3. 应定期检查和更新跳转路径配置，确保与业务需求一致
4. 对于需要参数的跳转路径，应使用路由参数而不是查询参数，提高URL的可读性和可维护性
5. 跳转前应检查用户权限，避免无效跳转

## 代理配置说明
前端请求统一添加`/api`前缀，通过前端开发服务器(Vite)或生产环境反向代理(Nginx)转发到后端，并自动去掉`/api`前缀，**后端无需处理该前缀**。

- 开发环境：通过Vite的`proxy`配置实现
- 生产环境：通过Nginx等反向代理实现
```javascript
// src/api/index.js
import axios from 'axios'
import auth from './modules/auth'
import ai from './modules/ai'
import chat from './modules/chat'
import enterprise from './modules/enterprise'
import user from './modules/user'
import search from './modules/search'
import common from './modules/common'

// 创建axios实例
const request = axios.create({
  baseURL: '/api',
  timeout: 10000
})

// 请求拦截器
request.interceptors.request.use(
  config => {
    // 添加token等认证信息
    const token = localStorage.getItem('token')
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  },
  error => {
    return Promise.reject(error)
  }
)

// 响应拦截器
request.interceptors.response.use(
  response => {
    return response.data
  },
  error => {
    // 统一错误处理
    let errorMsg = '请求失败'
    
    if (error.response) {
      // HTTP状态码错误
      const { status, data } = error.response
      
      switch (status) {
        case 401:
          errorMsg = '未授权，请重新登录'
          // 可以在这里处理登录过期逻辑，如跳转到登录页
          // localStorage.removeItem('token')
          // window.location.href = '/login'
          break
        case 403:
          errorMsg = '拒绝访问'
          break
        case 404:
          errorMsg = '请求的资源不存在'
          break
        case 500:
          errorMsg = '服务器内部错误'
          break
        default:
          errorMsg = data?.msg || `请求错误 (${status})`
      }
    } else if (error.request) {
      // 网络错误
      errorMsg = '网络连接失败，请检查网络'
    } else {
      // 其他错误
      errorMsg = error.message || '请求失败'
    }
    
    // 可以在这里使用UI组件库的消息提示
    // ElMessage.error(errorMsg)
    
    return Promise.reject(error)
  }
)

export { request, auth, ai, chat, enterprise, user, search, common }

# 状态管理设计
```javascript
// src/store/modules/auth.js
import { defineStore } from 'pinia'
import { auth as authApi } from '@/api'
import router from '@/router'

export const useAuthStore = defineStore('auth', {
  state: () => ({
    userInfo: null,           // 用户详细信息
    token: localStorage.getItem('token') || '',  // 认证token
    expireTime: localStorage.getItem('expireTime') || null,  // token过期时间
    isAuthenticated: !!localStorage.getItem('token'),  // 是否已认证
    userRoles: JSON.parse(localStorage.getItem('userRoles') || '[]')  // 用户角色
  }),
  
  getters: {
    // 检查token是否过期
    isTokenExpired: (state) => {
      if (!state.expireTime) return true
      return new Date().getTime() > new Date(state.expireTime).getTime()
    },
    // 检查用户是否有某个角色
    hasRole: (state) => (role) => {
      return state.userRoles.includes(role)
    }
  },
  
  actions: {
    async login(userData) {
      try {
        const res = await authApi.login(userData)
        if (res.success) {
          this.token = res.data.token
          this.userInfo = res.data.userInfo || res.data
          this.expireTime = res.data.expireTime
          this.isAuthenticated = true
          this.userRoles = res.data.roles || []
          
          // 保存到localStorage
          localStorage.setItem('token', res.data.token)
          if (res.data.expireTime) {
            localStorage.setItem('expireTime', res.data.expireTime)
          }
          if (res.data.roles) {
            localStorage.setItem('userRoles', JSON.stringify(res.data.roles))
          }
        }
        return res
      } catch (error) {
        console.error('登录失败:', error)
        return { success: false, msg: '登录失败' }
      }
    },
    
    async register(userData) {
      try {
        const res = await authApi.register(userData)
        return res
      } catch (error) {
        console.error('注册失败:', error)
        return { success: false, msg: '注册失败' }
      }
    },
    
    async logout() {
      try {
        const res = await authApi.logout(this.token)
        // 无论后端是否成功，都清除前端认证信息
        this.clearAuthInfo()
        return res
      } catch (error) {
        console.error('登出失败:', error)
        // 即使请求失败，也清除前端认证信息
        this.clearAuthInfo()
        return { success: false, msg: '登出失败' }
      }
    },
    
    // 清除认证信息
    clearAuthInfo() {
      this.token = ''
      this.userInfo = null
      this.expireTime = null
      this.isAuthenticated = false
      this.userRoles = []
      
      // 清除localStorage
      localStorage.removeItem('token')
      localStorage.removeItem('expireTime')
      localStorage.removeItem('userRoles')
      
      // 跳转到登录页
      router.push('/login')
    },
    
    // 刷新token
    async refreshToken() {
      try {
        const res = await authApi.refreshToken(this.token)
        if (res.success) {
          this.token = res.data.token
          this.expireTime = res.data.expireTime
          
          // 更新localStorage
          localStorage.setItem('token', res.data.token)
          if (res.data.expireTime) {
            localStorage.setItem('expireTime', res.data.expireTime)
          }
        } else {
          // 刷新失败，清除认证信息
          this.clearAuthInfo()
        }
        return res
      } catch (error) {
        console.error('刷新token失败:', error)
        this.clearAuthInfo()
        return { success: false, msg: '刷新token失败' }
      }
    },
    
    // 更新用户信息
    async updateUserInfo(userData) {
      try {
        const res = await authApi.updateUserInfo(userData)
        if (res.success && res.data) {
          this.userInfo = { ...this.userInfo, ...res.data }
        }
        return res
      } catch (error) {
        console.error('更新用户信息失败:', error)
        return { success: false, msg: '更新用户信息失败' }
      }
    }
  }
})
```

      { path: '/chat', component: () => import('@/views/chat/ChatSessionList.vue'), meta: { title: '消息中心' } },
      
      // 搜索模块
      { path: '/search', component: () => import('@/views/search/SearchResult.vue'), meta: { title: '搜索结果' } },

      { path: '/setting', component: () => import('@/views/setting/Setting.vue'), meta: { title: '系统设置' } },
      { path: '/report', component: () => import('@/views/report/Report.vue'), meta: { title: '报表统计' } }
    ]
  },
  
  // 无需登录的页面
  {
    path: '/',
    component: BlankLayout,
    meta: { requiresAuth: false },
    children: [
      { path: '/login', component: () => import('@/views/login/Login.vue'), meta: { title: '登录' } },
      { path: '/register', component: () => import('@/views/login/Register.vue'), meta: { title: '注册' } },
      { path: '/403', component: () => import('@/views/error/403.vue'), meta: { title: '无权限访问' } },
      { path: '/404', component: () => import('@/views/error/404.vue'), meta: { title: '页面不存在' } },
      { path: '/500', component: () => import('@/views/error/500.vue'), meta: { title: '服务器错误' } }

  { path: '/:pathMatch(.*)*', redirect: '/404' }

const router = createRouter({
  history: createWebHistory(),
  routes
})

// 路由守卫
router.beforeEach(async (to, from, next) => {
  // 设置页面标题
  document.title = to.meta.title ? `${to.meta.title} - 企业服务平台` : '企业服务平台'
  
  // 登录验证
  if (to.meta.requiresAuth) {
    // 检查是否有token
    if (!localStorage.getItem('token')) {
      next('/login')
      return
    }
    
    // 可以在这里添加token过期检查逻辑
    // 从auth store中检查token是否过期
    const authStore = useAuthStore()
    if (authStore.isTokenExpired) {
      try {
        // 尝试刷新token
        await authStore.refreshToken()
      } catch (error) {
        // 刷新失败，跳转到登录页
        next('/login')
        return
      }
    }
    
    // 角色权限检查
    if (to.meta.roles && to.meta.roles.length > 0) {
      if (!authStore.hasRole(to.meta.roles)) {
        // 没有权限，跳转到403页面
        next('/403')
        return
      }
    }
  }
  
  next()
})

export default router
