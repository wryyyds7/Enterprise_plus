# 现有前端页面及特征

## 一、项目结构概述

项目使用 Vue 3 + Element Plus 开发，采用模块化的路由、API 和状态管理设计。主要目录结构如下：

- `src/api/` - API 接口定义，按模块划分
  - `modules/` - 各功能模块的 API 接口
  - `index.js` - API 入口文件
- `src/assets/` - 静态资源文件
- `src/components/` - 通用组件
- `src/layouts/` - 布局组件
- `src/router/` - 路由配置，按模块划分
  - `modules/` - 各功能模块的路由配置
  - `index.js` - 路由入口文件
- `src/store/` - 状态管理
  - `modules/` - 各功能模块的状态管理
  - `index.js` - 状态管理入口文件
- `src/utils/` - 工具函数
- `src/views/` - 页面组件，按功能模块划分
  - 各功能模块目录，包含具体页面组件和模块入口文件
- `src/App.vue` - 根组件
- `src/main.js` - 应用入口文件
- `src/style.css` - 全局样式文件

## 二、现有页面及特征

### 1. 布局组件

#### BaseLayout.vue
- **URL**：/admin/*（所有管理员页面）
- **功能**：提供侧边栏导航 + 主内容区的布局
- **特征**：
  - 侧边栏宽度200px，支持折叠/展开

  - 支持按角色权限过滤菜单

#### NavigationHeader.vue
- **URL**：/home/*, /search/*, /forum/*, /ai/*, /chat/*（用户页面）
